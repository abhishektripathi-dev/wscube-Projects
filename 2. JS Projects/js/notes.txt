Lexical Scope

Lexical scope means that the scope (accessibility of variables) is determined by the physical location of code at the time it is written, not when it is executed.

let name = "Global";

function printName() {
  console.log(name);
}

function test() {
  let name = "Local";
  printName();
}

test();


Callback

A function passed as an argument to another function, which is executed later.

function greet(name) {
  console.log("Hello " + name);
}

function demo(callback) {
  let name = "Abhishek";
  callback(name);
}

demo(greet);


map()

1. Iterates over each element of an array
2. Returns a new array of same length
3. Does NOT modify the original array

let arr = [1, 2, 3, 4];

let doubled = arr.map(el => el * 2);

console.log(doubled);   // [2, 4, 6, 8]
console.log(arr);   // [1, 2, 3, 4] (unchanged)


filter()

1. Iterates over each element
2. Executes a callback for each element
3. Returns a new array with less or same length
4. Does NOT modify the original array

let arr = [1, 2, 3, 4, 5];

let even = arr.filter(num => num % 2 === 0);

console.log(even);    // [2, 4]
console.log(arr); // [1,2,3,4,5] (unchanged)


forEach()

forEach() is a array method used to iterate over elements of an array


Executes a callback for each element
Does not return anything (undefined)
Does not create a new array
Is mainly used for side effects

let arr = [1, 2, 3];

arr.forEach(num => {
  console.log(num * 2);
});
